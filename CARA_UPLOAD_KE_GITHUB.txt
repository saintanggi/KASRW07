CARA UPLOAD KE GITHUB DAN DEPLOY - RW 07

1. Extract ZIP ini.
2. Upload semua isi folder KASRW07 ke repo GitHub Anda.
3. Jika memakai Git command:
   git add .
   git commit -m "fix: notifikasi dan badge dummy rw07"
   git push origin main

4. Jika database belum dibuat, jalankan di Supabase SQL Editor:
   supabase/RESET_DATABASE_RW07.sql

5. Untuk mengosongkan data dummy dan mengaktifkan login/RLS, jalankan:
   supabase/RESET_EMPTY_LOGIN_RW07.sql

6. Buat akun pengurus di Supabase:
   Authentication > Users > Add user

7. Di Vercel, isi Environment Variables:
   VITE_SUPABASE_URL=https://PROJECT-REF.supabase.co
   VITE_SUPABASE_ANON_KEY=ANON_KEY_ANDA

8. Redeploy Vercel.

Perbaikan tambahan di ZIP ini:
- Badge angka 3 di menu Pengeluaran sudah dihapus.
- Badge notifikasi palsu sudah dihapus.
- Dropdown notifikasi bisa dibuka, ditutup, dan ditandai dibaca.
- Tombol Notifikasi di sidebar diarahkan ke Audit Trail.

JANGAN upload node_modules, dist, atau file .env. ZIP ini sudah tidak menyertakan file-file tersebut.
